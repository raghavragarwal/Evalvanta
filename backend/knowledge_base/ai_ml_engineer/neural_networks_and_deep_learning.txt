Neural Networks and Deep Learning

A neural network learns a composition of simple functions -- linear transformations followed by nonlinear activation functions -- whose combined effect can approximate very complex mappings between inputs and outputs. The nonlinearity is what gives the network its expressive power; a stack of purely linear layers, no matter how deep, collapses mathematically into a single linear transformation. Common activation functions include ReLU (which zeroes out negative values and passes positive values through unchanged), sigmoid, and tanh. ReLU's popularity in deep networks comes largely from how it affects gradient flow during training: unlike sigmoid and tanh, which saturate and produce near-zero gradients for large-magnitude inputs, ReLU's gradient is a constant 1 for any positive input, which helps gradients propagate through many layers without vanishing.

Backpropagation is the algorithm that makes training deep networks computationally feasible. It applies the chain rule of calculus to efficiently compute the gradient of the loss with respect to every parameter in the network, working backward from the output layer to the input layer, reusing intermediate computations rather than recomputing them from scratch for each parameter. Without this reuse, computing gradients for a network with millions of parameters would be computationally intractable; backpropagation turns it into a cost roughly proportional to a single forward pass through the network.

The vanishing and exploding gradient problems are direct consequences of the chain rule applied across many layers: gradients are products of many terms, and if those terms are consistently less than one in magnitude, the product shrinks toward zero as it propagates backward through more layers (vanishing), making early layers train extremely slowly. If the terms are consistently greater than one, the product grows without bound (exploding), causing unstable training and numerical overflow. Architectural innovations like residual connections (which let gradients skip directly across layers via an identity shortcut) and normalization techniques like batch normalization or layer normalization were developed specifically to keep gradient magnitudes well-behaved as network depth increases, which is part of why very deep networks only became practically trainable after these techniques were introduced.

Convolutional layers exploit a specific structural assumption about the data: that local patterns matter, and that a pattern useful in one part of the input (like an edge in an image) is likely to be useful elsewhere too. Instead of learning a separate full set of weights for every pixel position, a convolutional layer learns a small set of filters that slide across the entire input, sharing weights across positions. This weight sharing dramatically reduces the number of parameters compared to a fully connected layer of similar receptive field, and it also gives the resulting features a useful property called translation equivariance -- shifting the input shifts the resulting feature map by a corresponding amount, rather than producing an unrelated output.

Attention mechanisms, and the transformer architecture built around them, address a different structural assumption: that the relevance of one part of a sequence to another shouldn't be limited by their distance apart, the way it effectively is in a recurrent network that processes tokens one at a time and can struggle to preserve information over long sequences. Self-attention computes, for every position in a sequence, a weighted combination of every other position, with the weights learned based on how relevant each pair of positions is to each other. This gives the model direct access to long-range dependencies in a single layer, at the cost of computation and memory that scales quadratically with sequence length, which is why much of the recent architectural research in this area focuses on making attention more efficient at longer sequence lengths.
